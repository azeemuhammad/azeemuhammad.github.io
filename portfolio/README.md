# Muhammad Daniyal Azeem — Portfolio Website

Modern, advanced-level personal portfolio built for **Muhammad Daniyal Azeem**.

## Features

- **Responsive** single-page design (mobile-first)
- **Dark / Light** theme toggle (persisted in localStorage)
- Smooth scroll + active navigation highlighting
- Scroll-triggered reveal animations
- Animated counters and floating badges
- Glassmorphism cards & modern gradient accents
- Project showcase with GitHub links
- Contact form (opens mail client)
- SEO-friendly meta tags

## Tech Stack

- Pure HTML5
- Modern CSS (CSS variables, Grid, Flexbox, backdrop-filter)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Inter + Space Grotesk)
- Font Awesome 6 icons

## How to Use
